# SAMUELECARENZI.COM / BOOT SEQUENCE v2.1

Pacchetto completo del prototipo locale, aggiornato dalla versione SCROLL v2.

## Modifiche rispetto alla v2
- Titolo a sinistra: `BOOT SEQUENCE // INITIALIZING`, che diventa `BOOT SEQUENCE // ACTIVATED` quando la barra raggiunge 100%.
- Sottotitolo: `IDEA → DESIGN → BUILD → ONLINE`.
- Indicatore a destra: `01 / IDEA`, `02 / DESIGN`, `03 / BUILD`, `04 / ONLINE`.
- Etichette dei quattro moduli aggiornate per coerenza.
- Barra upload invariata (controllata dallo scroll) e messaggio finale `SYSTEM ACTIVATED`.
- Nessun cambiamento a stili, velocità, traiettorie o sezioni del sito.

## Installazione sicura
1. Fai un backup della cartella del prototipo locale attuale.
2. **Opzione semplice:** estrai l'intera cartella dello ZIP in una nuova directory e apri `index.html`, senza mescolare vecchie versioni.
3. **Opzione per modifiche minime:** sostituisci esclusivamente `index.html` e `fn-scroll.js` nella tua cartella attuale della versione v2. Gli altri file restano identici.
4. Aggiorna Chrome con Ctrl+F5 e verifica scroll in avanti/indietro.
